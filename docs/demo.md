# Five-minute demonstration

Use the unpaid fallback from the README with `--provider scripted-approval` and a
separate archive. The footer must say **No API spend**. In hosted mode the same Start
button sends requests to Anthropic and consumes your own configured ceiling.

1. **Investigate:** choose Dependency timeout and Adaptive. Start, read the condition
   and uncertainty, and click a numbered citation. Evidence inspector shows the stable
   ID, content hash, payload and coverage. The observation is a shipping timeout; the
   underlying delay mechanism remains unknown.
2. **Compare:** run the same case with Fixed, then Compare runs. Select the fixed and
   adaptive pair. In this scripted example, fixed uses six dispatches and adaptive two.
   That is a programmed software demonstration, not evidence of superior model quality.
3. **Missing data:** run Missing evidence. Inspect metric records in Evidence inspector.
   `samples: []`, `missing_intervals` and `complete: false` describe missing observations,
   not measured zero or a healthy dependency.
4. **Context:** run the handcrafted trace demonstration. Open Investigation context and
   filter the UTC timeline to trace spans. Inspect trace, span and parent IDs. Read the
   hypothesis and uncertainty. The fixture is handcrafted; real instrumentation belongs
   to the separate Docker laboratory.
5. **Review:** open Review report. Split one sentence into factual atomic claims, choose
   judgments and attach evidence. Save a draft and reload. Finalize only after you have
   actually checked every unit and can make the named completeness attestation. This
   public claim review is separate from evaluator-only benchmark scoring.

## Approval and restart

Select Approval and restart demonstration with Adaptive. After collecting logs in
09:55–10:05 UTC, the scripted provider requests metrics across 09:50–10:05. The UI pauses
before collection. Note the run ID; stop and restart the server with the same archive
and provider. Refresh, select the pending Recent run, and inspect the exact query.
Approve exact query to continue. Start another run and try Decline and finalize.
Workflow shows the selected run's recorded node path. Waiting does not use active time.

## Other controls

Recent runs reopens saved investigations. Five Handcrafted stress fixtures illustrate
simultaneous faults, nearby changes, intermittent failures, incomplete telemetry and
slow successful requests. The scripted provider is intentionally limited and may miss
conditions. Refresh captures scans locally generated captures. The Benchmark tab starts
empty in this public export; real generated experiment summaries populate it later.

## If a live demonstration fails

Switch to the unpaid scripted server with its own archive and replay the same features.
State that this proves interaction/orchestration, not hosted-model availability. No
database or external model is required after dependencies are installed and the UI built.
