# Dependency attribution

The project has no selected license. Its dependencies have independent licenses.
No third-party source, virtual environment, node_modules or built UI is committed.
Installation retains the license files supplied by each package. Redistribution of
built bundles or container images requires retaining applicable upstream notices.

This inventory comes from installed Python metadata and the checked-in npm lockfile.
A short license field is descriptive metadata, not a replacement for the actual license.
